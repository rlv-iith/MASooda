# Reproducing the Week 6 results

Every Week 6 CSV, figure, README table and `outputs/week6/RESULTS.md` is regenerated by one
command. Results are **provisional** while `experiments.week6.provisional: true`.

## Requirements

- Python ≥ 3.10 (developed on 3.14, compiled under 3.11)
- numpy, pyyaml, matplotlib (Pillow comes with matplotlib); pytest for the tests only
- Optional: ffmpeg on `PATH` for MP4 videos (otherwise the demo video is written as a GIF)
- About 300 MB free disk for a full run (per-run series, telemetry and snapshots)

## Install

With [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

With pip:

```bash
python -m venv .venv
```

```bash
.venv/bin/pip install numpy pyyaml matplotlib pytest
```

(Windows: `.venv\Scripts\pip install numpy pyyaml matplotlib pytest`.)

## One command

Linux / macOS / Git Bash:

```bash
scripts/run_all.sh
```

Windows PowerShell:

```bash
powershell -ExecutionPolicy Bypass -File scripts\run_all.ps1
```

Both call `scripts/run_all.py` with the same arguments and pick `.venv`'s Python when it exists
(override with the `PYTHON` environment variable). Flags:

| Flag | Effect |
|---|---|
| `--quick` | smoke version: 1 seed, 12 agents, 20 s; outputs under `outputs/week6/_quick/`; under 1 minute |
| `--only e1,e4` | only those experiments' run and plot stages (plus env, smoke, summary, video) |
| `--skip-video` | no dashboard video |
| `--workers N` | parallel simulations (default: all CPUs) |
| `--fresh` | re-run every simulation instead of resuming from `runs.csv` |

`run_all` does **not** run pytest. It logs every stage with its time to `outputs/week6/run_all.log`,
lists every expected artifact as present / missing, and exits non-zero if any is missing.

## Expected runtime

Measured on an Intel i5-12500H laptop (12 cores, Windows 11) with 12 workers:

| Stage | Time |
|---|---|
| E1 (24 runs) | 2.4 min |
| E2 (12 runs) | 1.2 min |
| E3 (24 runs) | 2.4 min |
| E4 (57 runs) | 4.3 min |
| E5 (18 extra runs) | 1.1 min |
| E6 (6 runs) | 0.9 min |
| Plots, static figures, RESULTS.md | ~1 min |
| Demo video (MP4 + 3 clips) | 4.3 min |
| **Total** | **≈ 17 min** |
| `--quick` from scratch | 54 s |

A single 60-agent, 180 s run takes about 30 s on one core. Runs resume: an interrupted
`run_all` continues where it stopped.

## Where the outputs go

| Path | Contents |
|---|---|
| `outputs/week6/<experiment>/runs.csv` | one row per simulation (all metrics) |
| `outputs/week6/<experiment>/summary.csv` | mean, std, n, 95% CI per group |
| `outputs/week6/<experiment>/manifest.json` | command, commit, config hash, seeds, versions, timings |
| `outputs/week6/<experiment>/README.md` | generated tables, method, weak groups, observations |
| `outputs/week6/<experiment>/{series,calls,telemetry,occupancy,frames}/` | per-run time series |
| `outputs/week6/figures/` | every figure as PNG (300 dpi) + PDF |
| `outputs/week6/RESULTS.md` | consolidated results page |
| `outputs/week6/demo/` | fallback demo video, clips, demo run files |

Experiment folders: `e1_admm_scaling`, `e2_formation`, `e3_priority`, `e4_resilience`, `e5_stl`,
`e6_degradation`.

## Changing seeds or fleet sizes

All experiment matrices live in `configs/base_config.yaml` under `experiments.week6.matrices`
(`seeds`, `agent_counts`, `architectures`, `attack_enabled`, `link_failure`, `admm_max_iterations`,
`attack_offset_m`, …). Edit them and run `scripts/run_all.sh`: runs already in `runs.csv` are
reused, new combinations are added. Changing a *simulation* parameter (any section other than
`experiments` and `visualization`) moves old rows to `runs_archive.csv`, so summaries only use
results from the current configuration.

Same seed and configuration → identical `runs.csv` (excluding `wall_time_s`), checked by running
the quick matrices twice from a clean copy.

## Regenerating figures only

Each plot script reads the CSVs only:

```bash
python scripts/week6_e4_plot.py
```

Or all of them without re-simulating:

```bash
python scripts/run_all.py --skip-video
```

(with existing `runs.csv` files every run stage resumes instantly).
